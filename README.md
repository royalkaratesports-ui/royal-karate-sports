# Royal Karate Sports

Coach-led academy website. Akash Kishor Shinde is presented as Founder & Head Coach, with the owner-supplied portrait, biography, real training photos and archived records.

## Open the website — no server needed

1. Extract the complete ZIP to a folder.
2. Open `royal-karate-sports/index.html` in Chrome, Edge or another modern browser.
3. Keep `assets/`, both Royal stylesheets and the JavaScript files next to the HTML pages. Do not open an individual HTML file inside the ZIP.

All navigation, programme selection, archive readers and local enquiry-draft download work from the extracted folder.

## Optional local web server

From this folder:

```
python -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`. That address works only on the same computer and only while the command is running. This package has not been deployed to royalkaratesports.com.

## Edit and build

The Python content modules in `tools/` are the source of truth. Generated HTML should not be edited in isolation.

Use Python 3.11 or newer. Install the development dependencies and the browser once:

```sh
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
```

Then build and verify in this order (release tests need the ZIP generated by the packager):

```sh
python tools/build.py
python tools/verify_redesign.py
python tools/accessibility.py
python tools/package.py
python -m unittest discover -s tools -p "test_*.py"
```

For the extended inner-page browser tests, set `ROYAL_BROWSER_TEST=1` before the final command (bash: `ROYAL_BROWSER_TEST=1 python -m unittest discover -s tools -p "test_*.py"`; PowerShell: `$env:ROYAL_BROWSER_TEST="1"` then run the command).

The package is written to `../Royal-Karate-Sports-v19.zip`. Development uses BeautifulSoup, Playwright Chromium, Pillow and Requests, pinned in `requirements-dev.txt`. No packages or external network dependencies are needed to view the built website. See `GITHUB.md` for repository structure and optional hosting.

Main sources: `tools/home_content.py`, `tools/royal_shell.py`, `tools/royal_inner.py`, the factual page-content modules, `royal.css`, `royal-pages.css`, and the shared/page-specific scripts. See `DESIGN.md` and `ASSETS.md`.

## Content and privacy

- Regular training is completely free; Dharavi and Pratiksha Nagar are the supplied centres. Confirm timings and meeting instructions before attending.
- Phone/email are direct-contact links. Facebook/Instagram appear in the footer.
- The form prepares an **UNSENT local draft**. It does not submit a message, book a class, register a camper or reserve a place. Call or email the academy for a response.
- No analytics, remote form endpoints or browser storage are used.
- Recognition records and scans are owner-supplied. A Padma nomination is not an award received. Authenticity/official status is not independently verified.
- Supplied portraits and training photographs are preserved full-frame. The separate illustrative stock gallery is explicitly labeled.
- Schedules, safeguarding arrangements, hosting and production privacy terms require owner approval. Search indexing remains disabled.
